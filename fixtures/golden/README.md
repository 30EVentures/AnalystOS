# Golden fixture

This folder will hold one canonical worked example: a set of source documents
plus the correct answers a good analyst would produce from them.

Once it exists, every build runs against it. It is three things at once:

- the regression check — did a change break a known-good answer?
- the demo — here is AnalystOS working end to end
- the definition of "better"
