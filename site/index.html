How it works

A layered stack, not a black box

Each layer adds one thing. The layer below it is its source of truth — so nothing downstream can drift from the evidence.

L0

Evidence kernel

Every source stored once, addressed by the hash of its exact contents. Tamper-evident by construction.

L1

Structure layer

Raw tables become typed, schema-checked data — a bad value is rejected, not silently accepted.

L2

Reasoning layer

Lookups and computed metrics — growth, margin, ratio — each returning an answer and a citation.

L4

Deliverable

A written, footnoted section — plain text, formatted HTML, or a page ready to print to PDF.
